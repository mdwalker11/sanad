# Sanad Admin Dashboard

هذه نسخة تشغيلية أولية لواجهة لوحة التحكم، مستقلة عن تطبيق الهاتف. في الإصدار الإنتاجي ستتصل بـ Backend موثق وتحتاج مصادقة وصلاحيات مشرف.

## الأقسام المخططة

- الطلبات الحية.
- العاملون والوثائق.
- العروض والأسعار.
- التسويات والعمولات.
- الشكاوى والضمان.
- المناطق والتغطية.
- التقارير.

## الحالة

الهيكل الأولي لمشروع Flutter وتطبيق سند موجود في الجذر. لوحة الإدارة الإنتاجية لم تُربط بعد بقاعدة بيانات أو مصادقة؛ لا تعتبر جاهزة للنشر قبل تنفيذ Backend واختبارات الصلاحيات.
