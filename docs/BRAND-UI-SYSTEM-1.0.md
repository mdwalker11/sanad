# هوية سند البصرية — v1.0

## الفكرة
سند هو المساعد المحلي الموثوق للمنزل في طرابلس: خدمة إنسانية، واضحة، عملية، وهادئة.

## شخصية العلامة
- موثوقة بلا تعقيد.
- ليبية ومحلية.
- دافئة وقريبة من المستخدم.
- عملية وسريعة.
- شفافة في السعر والموعد والحالة.

## الشعار اللفظي
**سندك في كل خدمة منزلية**

بديل واجهة البداية:
**العناية بالمنزل، بطريقة أذكى**

## لوحة الألوان
- أخضر سند الأساسي: `#164C3B` — الثقة، الخدمة، الاستقرار.
- أخضر فاتح: `#DFF3EA` — الهدوء، الخلفيات، حالات النجاح.
- خلفية التطبيق: `#F7F9F6` — نظافة وراحة بصرية.
- لون النص: `#15211C` — قراءة واضحة.
- لون التنبيه الدافئ: `#FFF1D6` — نصائح وتنبيهات غير حرجة.
- لون الحدود: `#E4ECE6` — فصل ناعم بين البطاقات.

## مبادئ UI
1. إجراء رئيسي واحد واضح في كل شاشة.
2. البطاقات مستديرة 22–28px مع حدود خفيفة بدل الظلال الثقيلة.
3. لا نستخدم لونًا قويًا إلا للإجراء أو الحالة.
4. كل شاشة عربية RTL ومناسبة للمساحات الصغيرة.
5. حالات التحميل والخطأ والفراغ تظهر بوضوح ولا تترك المستخدم حائرًا.
6. لا يظهر للمستخدم أي مصطلح تقني مثل RPC أو RLS.
7. السعر والموعد وحالة الطلب تظهر قبل التفاصيل الثانوية.

## مكونات أساسية
- زر رئيسي أخضر ممتلئ.
- زر ثانوي فاتح.
- بطاقة خدمة: أيقونة، اسم، وصف، سهم.
- بطاقة الحالة: لون خفيف، عنوان عربي، إجراء واضح.
- شريط تنقل سفلي: الرئيسية، طلباتي، حسابي.
- Hero هادئ في الصفحة الرئيسية مع CTA واحد.

## حالات المنتج
- نجاح: أخضر فاتح + أيقونة تحقق.
- انتظار: كهرماني فاتح + أيقونة ساعة.
- خطأ: أحمر فاتح + رسالة قابلة للفهم.
- لا توجد بيانات: شرح قصير + زر إنشاء أول طلب.

## الخط
النسخة الحالية تستخدم Arial النظامية لضمان ظهور العربية دون تحميل خارجي. يمكن لاحقًا إضافة خط عربي مرخص مثل IBM Plex Sans Arabic أو Noto Kufi Arabic كأصل داخل التطبيق بعد اعتماد ملف الخط.
